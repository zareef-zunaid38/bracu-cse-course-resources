# CSE370 — Lab guide

Lab faculty: TMD / NAHC. Back to the [course guide](../README.md). All of this is faculty-issued lab material, except the SQL revision guide.

Lab work is a large share of the marks in this course. The assessments are SQL queries written on paper, so practise writing queries by hand, not just running them.

## The project

The lab project is a small web application backed by a database, marked in an individual viva. The project itself is not included, but [`reference-demos/`](../reference-demos) has a PHP demo that a lab faculty showed the whole class, which shows how the frontend, backend and database connect.
