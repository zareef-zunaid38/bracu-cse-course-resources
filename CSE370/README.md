# CSE370 — Database Systems

Summer 2026 · theory: NFF · lab: TMD / NAHC. Back to the [main README](../README.md).

There are **no past papers** for this course (no previous semester's questions are shared), so the mock exam and the exam notes matter more here than in the other two courses.

## Start here (in this order)

1. **[Topic map](topics/cse370_topics.md)** — every topic, which exam it belongs to, and how the topics connect. The [course index](topics/course-index.md) lists every note.
2. **[Resources](resources/cse370_resources.md)** — for each topic: which slide deck, which practice sheet, which textbook chapter.
3. **[Exam notes](cse370_exam_notes.md)** — who writes each assessment (the midterm and final are central; quizzes are NFF's), how each quiz and exam went, and what was asked.
4. **The material** — faculty [slides](slides) (Lectures 1–12; several have a text version beside the PDF), and my [concept notes](concepts) for the post-midterm topics 19–24 (indexing, query processing and optimization, transactions, concurrency control). For earlier topics, the slides and the resources map are what you have.
5. **Practice** — faculty [practice sheets](practice), the [mock final](mock-exams/cse370_final_mock_exam.md), and the [revision guides](revision-guides).
6. **Labs** — the [lab guide](lab/README.md). The labs carry a lot of marks here.
