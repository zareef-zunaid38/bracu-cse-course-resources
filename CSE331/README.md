# CSE331 — Theory of Computation

Summer 2026 · theory only: TNF. Back to the [main README](../README.md).

There are **no faculty lecture slides** for this course, so the [lecture notes](lecture-notes) here (19 lectures, transcribed from handwritten class notes) stand in for them. The course follows Sipser's *Introduction to the Theory of Computation* (3rd ed.), which is not hosted here.

## Start here (in this order)

1. **[Topic map](topics/cse331_topics.md)** — every topic, the dependency graph between them, and a study order. The [course index](topics/course-index.md) lists all the lecture notes.
2. **[Resources](resources/cse331_resources.md)** — Sipser chapters per topic, MIT OCW lectures, class recordings, and the extra lecture notes TNF shared.
3. **[Exam notes](cse331_exam_notes.md)** — who writes each assessment (the midterm and final are central; quizzes and assignments are TNF's), the pattern of every quiz and exam, and how the marking worked.
4. **[Lecture notes](lecture-notes)** — read them in order; each starts from the previous one.
5. **Past papers** — [index](pyq/pyq_index.md) and the [final pattern analysis](pyq/CSE331_final_probable_questions.md).
6. **Practice** — [practice sheets](practice), the [mock final](mock-exams/cse331_final_mock_exam.md), and the [revision guides](revision-guides).
