# CSE331 — Lecture 7: Regular Expressions

## Definition

A regular expression is a combination of symbols and operations that define all the strings that exist in a language.

Example alphabets used below: $\Sigma_1 = \{0, 1\}$, $\Sigma_2 = \{a, b, c\}$.

## Worked Examples

For each property below, $\Sigma$ denotes the alphabet in use (typically $\{0,1\}$ unless noted).

**String starts with 1:**
$$1(0 \cup 1)^* \quad \text{or, using } \Sigma^* \text{ as shorthand: } \quad 1\Sigma^*$$

**Contains substring 101:**
$$\Sigma^* 101 \Sigma^*$$

**Length is even:**
$$(\Sigma\Sigma)^* \quad \text{e.g. } ((0\cup1)(0\cup1))^*$$

**Length is odd:**
$$\Sigma(\Sigma\Sigma)^* \quad \text{alternatively } (\Sigma\Sigma)^*\Sigma$$

**Length is a multiple of 3:**
$$(\Sigma\Sigma\Sigma)^*$$

**Length is $3n+2$:**
$$\Sigma\Sigma(\Sigma\Sigma\Sigma)^* \quad \text{alternatively } (\Sigma\Sigma\Sigma)^*\Sigma\Sigma, \quad \Sigma(\Sigma\Sigma\Sigma)^*\Sigma$$

**Length is exactly 3:**
$$\Sigma\Sigma\Sigma$$

**Length is at least 3:**
$$\Sigma\Sigma\Sigma\Sigma^*$$

**Length is at most 3** (covers lengths 0, 1, 2, 3):
$$\varepsilon \cup \Sigma \cup \Sigma\Sigma \cup \Sigma\Sigma\Sigma$$

**Contains 0 exactly 3 times:**
$$1^*01^*01^*01^*$$

**Contains at least 3 0's:**
$$\Sigma^*0\Sigma^*0\Sigma^*0\Sigma^*$$

**Contains at most 3 0's:**
$$1^* \cup 1^*01^* \cup 1^*01^*01^* \cup 1^*01^*01^*01^*$$

**Ends with 01 or 10:**
$$\Sigma^*01 \cup \Sigma^*10 \quad \text{alt: } \Sigma^*(01 \cup 10)$$

**$L_1$ = starts and ends with the same symbol** (assumes $\varepsilon$ is *not* included in $L_1$):
$$0\Sigma^*0 \cup 1\Sigma^*1 \cup 1 \cup 0$$

**$\overline{L_1} = \Sigma^* \setminus L_1$** ($\varepsilon$ *is* included in the complement):
$$0\Sigma^*1 \cup 1\Sigma^*0 \cup \varepsilon$$

**First and 3rd symbol are the same** (if they exist):
$$0\Sigma0\Sigma^* \cup 1\Sigma1\Sigma^* \cup \varepsilon \cup \Sigma \cup \Sigma\Sigma$$

The complement $\overline{L_1} = \Sigma^*\setminus L_1 = 0\Sigma^*1 \cup 1\Sigma^*0 \cup \varepsilon$ — $\varepsilon$ is added back in because it fails "starts and ends with the same symbol" (nothing to compare), so it's excluded from $L_1$ but must appear in the complement.
