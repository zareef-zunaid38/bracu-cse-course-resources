## Regular Expression Identities

$$R\cdot\varepsilon = R \qquad R\cdot\emptyset = \emptyset \qquad R+\varepsilon = R+\varepsilon \qquad R+\emptyset = R$$

- $R\cdot\varepsilon = R$ — $\varepsilon$ is the identity element for concatenation.
- $R\cdot\emptyset = \emptyset$ — $\emptyset$ is absorbing under concatenation (concatenating with the empty language yields the empty language).
- $R+\varepsilon = R+\varepsilon$ — **no further simplification in general.** Unlike $\emptyset$, $\varepsilon$ is *not* automatically absorbed into $R$ under union — this only reduces to $R$ if $\varepsilon \in L(R)$ already.
- $R+\emptyset = R$ — $\emptyset$ is the identity element for union.

$$\Sigma^+ = \Sigma\Sigma^* \;\to\; \text{length at least one}$$

## Pumping Lemma — Motivation

**Necessary condition** (not sufficient) for regularity.

Example languages:
- $A = \{0^n1^n \mid n \geq 0\}$ → **non-regular**
- $B = \{\text{equal number of 0's and 1's}\}$ → **non-regular**
- $C = \{\text{number of "01" substrings} = \text{number of "10" substrings}\} = \{\text{strings that start and end with the same symbol}\}$ → **regular**

**Key logical point:** if a language follows the Pumping Lemma, that does *not* prove it's regular — the Pumping Lemma gives a *necessary* condition only. But if a language does *not* follow the Pumping Lemma, that's sufficient to prove it's **non-regular** (contrapositive). This is why the lemma is used with **proof by contradiction**: assume the language is regular, derive that it must satisfy the lemma, then exhibit a string that breaks the lemma's conditions.

## Pumping Lemma — Statement

If $A$ is a regular language, there exists an integer $P$ (the **pumping length**) such that for any string $s \in A$ with $|s| \geq P$, if $s = xyz$, then:

(i) $xy^iz \in A$ for all $i \geq 0$
(ii) $|y| > 0$
(iii) $|xy| \leq P$

## Worked Proof: $A = \{0^n1^n \mid n \geq 0\}$ is Non-Regular

**Proof by contradiction.**

Assume $A$ is regular. Then $A$ must satisfy the Pumping Lemma for some pumping length $P$.

Choose the string $s = 0^P1^P = xyz$, so $|s| = 2P \geq P$.

Since $|xy| \leq P$ and the first $P$ symbols of $s$ are all 0's, $xy$ must lie entirely within that leading block of 0's — $xy$ **cannot contain a 1**, otherwise $|xy|$ would have to extend past position $P$, exceeding the bound $|xy|\leq P$. So $y$ consists only of 0's: $y = 0^k$ with $k > 0$ (condition (ii) requires $|y|>0$).

Pumping down with $i = 0$:
$$xy^0z = 0^{P-k}1^P$$

Since $k > 0$, this string has fewer 0's than 1's, so $xy^0z \notin A$.

This contradicts condition (i) of the Pumping Lemma (which requires $xy^iz \in A$ for **all** $i \geq 0$, including $i=0$). Contradiction — therefore $A$ is **not** a regular language.

> [!note] Any single value of $i$ that breaks condition (i) is sufficient to complete the proof — $i=0$ is just the simplest choice here, since it directly produces a 0/1-count mismatch.
