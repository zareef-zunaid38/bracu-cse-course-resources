# CSE331 — Lecture 18: Decidability

New topic, opening after [Lecture 17](CSE331_lecture_17_2026-08-26.md)'s Turing Machine constructions: deciders vs. recognizers, the decidability of $A_{DFA}$, closure of decidable languages under union, the containment hierarchy (Regular ⊂ CFL ⊂ Decidable ⊂ Recognizable), and the classic diagonalization proof that $A_{TM}$ is undecidable (the Halting Problem).

## Decider vs. Recognizer

For a TM deciding whether $w$ is accepted:

- **Yes** branch → **(a)** accepting state.
- **No** branch → either **(i)** a rejecting state, or **(ii)** an infinite loop (the machine never halts).

| Halting behavior | Classification |
|---|---|
| (a) + (i) only | **Decider** — always halts (accept or reject) → **Turing-decidable language** |
| (a) + (i) + (ii) | **Recognizer** — may loop forever on some inputs → **Turing-recognizable language** |

> Deciding with a TM means determining whether a given input will be accepted *by another machine* — the decider's job is to simulate that other machine and always terminate with an answer.

## $A_{DFA}$ is decidable

$$A_{DFA} = \{\langle D, w\rangle : D \text{ is a DFA}, w \text{ is a string}, w \text{ belongs to the language of } D\}$$

Worked membership examples: $\langle \text{Even num of 0s}, 1\rangle$, $\langle \text{Even num of 0s}, 00\rangle$, $\langle \text{Even num of 0s}, 100\rangle$.

**Claim:** Let $M$ be a TM deciding $A_{DFA}$. On input $\langle D, w\rangle$, $M$:

1. Simulates the DFA $D$.
2. Runs the simulated $D$ on input $w$.
3. If the simulated $D$ accepts $w$, $M$ accepts $\langle D,w\rangle$; if the simulated $D$ rejects $w$, $M$ rejects $\langle D,w\rangle$.

$M$ always halts with an answer (a DFA simulation is guaranteed to terminate), so $M$ is a decider and $A_{DFA}$ is a decidable language.

### Worked example

Let $D$ be the DFA over $\{0,1\}$ with two states $q_{even}$ (start, accept) and $q_{odd}$: reading a $0$ flips between the two states, reading a $1$ leaves the state unchanged. $L(D)$ = strings with an even number of $0$s.

Trace $w = 100$: $q_{even}$ --(read $1$)--> $q_{even}$ --(read $0$)--> $q_{odd}$ --(read $0$)--> $q_{even}$. End state $q_{even}$ is accepting → **accept**. So $\langle D, 100\rangle \in A_{DFA}$.

Trace $w = 10$: $q_{even}$ --(read $1$)--> $q_{even}$ --(read $0$)--> $q_{odd}$. End state $q_{odd}$ is not accepting → **reject**. So $\langle D, 10\rangle \notin A_{DFA}$.

> **Note:** Explanation
> $M$ does not count steps toward a target of $|w|$ — it simply reads the next symbol of $w$ and updates $D$'s current state, one step at a time, until no symbols of $w$ remain. Since $w$ is finite, this process runs out of input after exactly $|w|$ steps and stops on its own; there is no way for it to loop, because a DFA's transition table only ever does "read one symbol, move to exactly one next state." Termination is forced by the input being consumed — not by an external counter check — and that is precisely what makes $M$ a decider rather than a mere recognizer.

## Decidable languages are closed under union

> Margin note (verbatim intent): *"Idea of how to solve it, not the solution itself"* — TNF's own sketch of the strategy, not a full proof; filled in below.

**Claim:** If $L_1$ and $L_2$ are decidable, then $L_1 \cup L_2$ is decidable.

**Proof.** Since $L_1$ and $L_2$ are decidable, there exist deciders $T_1$ and $T_2$: $T_1$ always halts on any input $w$, accepting iff $w \in L_1$; $T_2$ always halts on any input $w$, accepting iff $w \in L_2$.

Construct a new TM $T$ for $L_1 \cup L_2$. On input $w$, $T$:
1. Runs $T_1$ on $w$.
2. Runs $T_2$ on $w$.
3. Accepts if either run accepted; rejects if both rejected.

$T$ always halts: $T_1$ and $T_2$ are deciders, so both runs are each guaranteed to finish in finite time; running two finite computations one after the other remains finite.

$T$ is correct: $w \in L_1 \cup L_2 \iff w \in L_1 \text{ or } w \in L_2 \iff T_1 \text{ accepts } w \text{ or } T_2 \text{ accepts } w \iff T \text{ accepts } w$, which is exactly step 3's rule.

Since $T$ always halts with the correct answer, $T$ is a decider, so $L_1 \cup L_2$ is decidable. $\blacksquare$

> **Note:** Explanation
> The combination rule in step 3 isn't arbitrary — it falls straight out of what "union" means:
>
> | $T_1$ | $T_2$ | Union result |
> |---|---|---|
> | accept | accept | accept |
> | accept | reject | accept |
> | reject | accept | accept |
> | reject | reject | reject |
>
> Reject only when *both* reject — matching set union exactly. Worked trace, reusing $T_1$ = "even number of 0s" from the $A_{DFA}$ example above, and adding $T_2$ = "contains at least one 1":
>
> | $w$ | $T_1$ (even 0s) | $T_2$ (has a 1) | $T$ (union) |
> |---|---|---|---|
> | `00` | accept (two 0s) | reject (no 1) | **accept** |
> | `10` | reject (one 0) | accept | **accept** |
> | `000` | reject (three 0s) | reject | **reject** |
>
> `000` is the only case where both sub-deciders reject. The halting argument reuses the exact same "no loop possible" guarantee from the $A_{DFA}$ proof above — just inherited from two given deciders here, instead of built from one DFA simulation.

## Decidable languages are closed under complement

**Claim:** If $L$ is decidable, then $\overline{L}$ (its complement) is decidable.

**Proof.** Let $T$ be a decider for $L$: $T$ always halts on any input $w$, accepting iff $w \in L$.

Construct $T'$ for $\overline{L}$. On input $w$: run $T$ on $w$; if $T$ accepts, reject; if $T$ rejects, accept.

$T'$ always halts: $T$ is a decider, so running it is guaranteed to finish; flipping an already-halted answer adds no new risk of looping.

$T'$ is correct: $w \in \overline{L} \iff w \notin L \iff T \text{ rejects } w \iff T' \text{ accepts } w$, exactly the flip rule above.

Since $T'$ always halts with the correct answer, $T'$ is a decider, so $\overline{L}$ is decidable. $\blacksquare$

> **Note:** Explanation
> First given as a spoken aside while covering Lecture 19's HALT_TM proof, formalized here since it's this course's exact complement-closure theorem. This is the easier cousin of the Union proof above — only one given decider to flip, not two to combine. Worked trace, reusing $T$ = "even number of 0s" (so $\overline{L}$ = "odd number of 0s"):
>
> | $w$ | $T$ (even 0s) | $T'$ (odd 0s) |
> |---|---|---|
> | `100` | accept (two 0s) | **reject** (correct — 100 has an even, not odd, count) |
> | `10` | reject (one 0) | **accept** (correct — 10 has an odd count) |

## Containment hierarchy

```
Recognizable
└── Decidable
    └── CFL
        └── Regular language
```

Each class strictly contains the next: every regular language is context-free, every CFL is decidable, and every decidable language is recognizable — but not conversely.

## $A_{TM}$ is undecidable — the Halting Problem

$$A_{TM} = \{\langle M, w\rangle : M \text{ is a Turing machine}, w \text{ is a string}, M \text{ accepts } w\}$$

> The scan's first occurrence of this set's subscript was hard to read (looked like "TNF" rather than "TM") — normalized to $A_{TM}$ throughout, since every later occurrence on the same page is written unambiguously as $A_{TM}$, and the surrounding proof is the standard $A_{TM}$-undecidability argument.

**Proof by contradiction.** Suppose $A_{TM}$ were decidable, i.e. some TM $M$ decides $A_{TM}$ — on input $\langle M', w\rangle$, $M$ accepts iff $M'$ accepts $w$.

Construct a new TM $D$ that, on input $\langle M'\rangle$ (a single machine, run on *itself*), calls $M$ on $\langle M', \langle M'\rangle\rangle$:

- If $M'$ accepts $\langle M'\rangle$ → $D$ **rejects**.
- If $M'$ rejects $\langle M'\rangle$ → $D$ **accepts**.

Now run $D$ on its own description, $\langle D\rangle$:

- If $D$ accepts $\langle D\rangle$ → by $D$'s own definition, $D$ must **reject** $\langle D\rangle$.
- If $D$ rejects $\langle D\rangle$ → by $D$'s own definition, $D$ must **accept** $\langle D\rangle$.

Both cases contradict themselves, so $D$ cannot exist. Since $D$ was built directly from $M$ (assumed to exist), $M$ cannot be a decider either — therefore **$A_{TM}$ is not a decidable language**.
