## Pumping Lemma — Statement (recap)

**Class source:** whiteboard, ~2:05.

For any regular language $A$, and a string $s$ with $|s| \geq p$ (the pumping length), if $s = xyz$, then:

(i) $xy^iz \in A$ for all $i \geq 0$
(ii) $|xy| \leq p$
(iii) $|y| > 0$

## Worked Proof: $B = \{0^n1^n \mid n \geq 0\}$ is Non-Regular

**Class source:** whiteboard, ~2:54–14:11 (basic version); ~27:23–28:00 (general/rigorous restatement, done later in the same lecture after the closure-property discussion — reordered here to sit with the rest of the $B$ proof).

$B$ is defined in class as "equal number of 0's and 1's" (not the narrower $\{0^n1^n\}$ form) — the witness string chosen below just happens to also be in the narrower language.

**Proof by contradiction.** Assume $B$ is regular, so a pumping length $p$ exists.

Choose $s = 0^p1^p \in B$. Then $|s| = 2p \geq p$.

Since $|xy| \leq p$ and the first $p$ symbols of $s$ are all 0's, $xy$ lies entirely within the leading 0-block, so $y = 0^k$ for some $k > 0$.

- $i = 1$: $xy^1z = xyz = 0^p1^p$ — trivially in $B$, no contradiction here.
- $i = 2$: $xy^2z = 0^{p+k}1^p$. Since $k > 0$, the 0-count $p+k \neq p$, the 1-count — so $xy^2z \notin B$. This violates condition (i).

∴ $B$ is not a regular language.

### General/rigorous restatement of the same proof

Instead of just inspecting the leading block, write $x = 0^\alpha$, $y = 0^\beta$ ($\beta > 0$), $z = 0^{p-\alpha-\beta}1^p$, so $xyz = 0^p1^p = s$.

Pumping with $i = 2$:
$$xy^2z = 0^\alpha \cdot 0^{2\beta} \cdot 0^{p-\alpha-\beta}1^p = 0^{p+\beta}1^p = s'$$

0-count of $s'$ is $p+\beta$; 1-count is $p$. Since $\beta > 0$, $p + \beta \neq p$ — contradiction, same conclusion as above. This version makes explicit that the result holds for *any* valid split of $x$ and $y$ within the 0-block, not just a specific one.

> **Info:** Secondary material (not from class) — two faster alternatives
> From `CSE331_pumping_lemma_20_examples.md` (problem 2, "Equal number of 0's and 1's"): since $B$ (defined generally, any ordering) is broader than $\{0^n1^n\}$, there are two shortcuts that avoid redoing the pumping argument:
> 1. **Closure under intersection.** $B \cap 0^*1^* = \{0^n1^n\}$. $0^*1^*$ is regular; if $B$ were regular, the intersection would be regular too (regular languages are closed under intersection) — but $\{0^n1^n\}$ is already known to be non-regular (Lecture 10), contradiction.
> 2. **Reuse the $\{0^n1^n\}$ proof verbatim.** Because the witness string $0^p1^p$ and every step of the $xyz$-decomposition argument are identical for both languages, the exact same proof carries over just by relabelling the language — no new derivation needed.
>
> Related practice (from `CSE331_pumping_lemma_exercises_solutions.pdf`, same "compare block lengths" technique): #1 $\{a^kb^k\}$, #3 $\{a^nb^{n+1}\}$, #4 $\{a^nb^{2n}\}$, #14 $\{a^kw : |w|=k\}$.

## Worked Proof: $C = \{0^n \mid n \text{ is a perfect square}\}$ is Non-Regular

**Class source:** whiteboard, ~16:11–23:23.

(length of the string is a perfect square, unary alphabet)

**Proof by contradiction.** Assume $C$ is regular, pumping length $p$.

> **Note:** First instinct on the board was to let $p$ itself be a perfect square — crossed out, since $p$ is a fixed but *unknown* constant guaranteed by the lemma, not something we get to choose the form of.

Instead, choose the string so its length is a perfect square **by construction**: $s = 0^{p^2}$. Then $|s| = p^2 \geq p$.

$s = xyz$ with $|xy| \leq p$, so $0 < |y| \leq p$.

Pumping with $i=2$ gives the new string $s' = xy^2z$:
$$|s'| = |xyz| + |y| = |s| + |y| = p^2 + |y|, \quad 0 < |y| \leq p$$

So:
$$p^2 < |s'| \leq p^2 + p < p^2 + 2p + 1 = (p+1)^2$$

$|s'|$ lies strictly between the consecutive perfect squares $p^2$ and $(p+1)^2$, so $|s'|$ **cannot** itself be a perfect square. Hence $xy^2z \notin C$ — contradicts condition (i).

∴ $C$ is not a regular language.

> **Note:** The board also worked a small numeric sanity check ($x=2, y=3, z=5$) just to illustrate that pumping only adds $|y|$ to the total length — not a separate proof, just a concrete instance of the general argument above.

> **Info:** Secondary material (not from class) — independent confirmation + extra insight
> `CSE331_pumping_lemma_20_examples.md` (problem 10, "Perfect Squares") derives this **exact same proof** independently — same $\alpha/\beta$ decomposition, same choice of $i=2$, same squeeze $p^2 < p^2+\beta \leq p^2+p < (p+1)^2$. Strong cross-check that the class's technique is the standard one. Bonus not covered in class: $i=3$ also works (gives $p^2+2\beta$, still $< p^2+2p < (p+1)^2$); $i=0$ or $i=1$ *may* also work but weren't checked in the source. Larger $i$ values get progressively harder to guarantee land outside the next perfect square.
>
> Related practice: `CSE331_pumping_lemma_exercises_solutions.pdf` #12 $\{0^n : n \text{ is a power of 2}\}$ uses the identical "squeeze between two consecutive target values" idea ($2^p < 2^p+k \leq 2^p+p < 2^{p+1}$ for $p>1$), and #8 `DOUBLESQUARE` $=\{a^nb^n : n \text{ is a square}\}$ is the two-letter-alphabet version of $C$ itself.

## Worked Proof: $D = \{ww \mid w \in \Sigma^*\}$ is Non-Regular

**Class source:** whiteboard, ~23:23–24:29.

**Proof by contradiction.** Assume $D$ is regular, pumping length $p$.

Illustrative instance first: $w = 010$, so $s = ww = 010\,010$.

General choice for the proof: $w = 0^p1$, so $s = ww = 0^p1\,0^p1$. Then $|s| = 2p+2 \geq p$.

Since $|xy| \leq p$ and the first $p$ symbols are all 0's, $xy$ lies entirely in the **first** 0-block, so $y = 0^k$, $k > 0$.

Pumping changes only the first block's length, leaving the second $0^p1$ untouched:
$$xy^iz = 0^{\,p+(i-1)k}\,1\,0^p\,1$$

For $i \neq 1$ this makes the two halves of the string unequal in length (or in content) — the string is no longer of the form $ww$ for any single $w$. So $xy^iz \notin D$ for $i \neq 1$ — contradicts condition (i).

∴ $D$ is not a regular language.

> **Tip:** Tightened justification (added during cross-check, 2026-08-12 — not from class or secondary sources)
> "Unequal in length or content" is correct but informal. Full argument: let $m = p+(i-1)k$ be the new leading zero-run length, so $m \neq p$ (since $k>0$, $i\neq1$). The pumped string is $0^m1\,0^p1$, total length $L=m+p+2$.
>
> Suppose for contradiction $0^m1\,0^p1 = ww$ for some $w$. Two cases:
> - **$L$ odd:** impossible — $|ww|=2|w|$ is always even.
> - **$L$ even:** the string has exactly two 1's, and $ww$ has $2\times(\text{count of 1's in }w)$, so $w$ has exactly one 1: $w=0^a1\,0^b$ with $a+b=L/2-1$. Then $ww = 0^a1\,0^{a+b}1\,0^b$. Matching against $0^m1\,0^p1$ position by position: trailing run gives $b=0$; middle run then gives $a=p$; leading run gives $a=m$. So $m=p$ — contradicting $m\neq p$.
>
> Either way, $xy^iz \neq ww$ for any $w$, so $xy^iz \notin D$. This version is airtight under quiz-time pressure — cite the trailing-run argument if asked to justify the claim rather than just state it.

> **Note:** The specific case worked on the board pumped down/up around the first block ($0^{p+mk}$ vs. $0^p$ compared side by side) to show the mismatch directly — reconstructed here in the general $i$ form since the board work was partially cropped.

> **Info:** Secondary material (not from class) — why the witness string needs a marker symbol
> `CSE331_pumping_lemma_20_examples.md` (problems 15–16, "$ww$ and $w\#w$") works the same language with the same witness shape ($0^p1\,0^p1$) and reaches the same conclusion, but adds a point the class notes don't spell out explicitly: an *all-0's* witness like $0^p0^p$ would **fail** to give a proof, because pumping an even number of 0's in or out keeps both halves equal (still of the form $0^m0^m$) — no contradiction results. The `1` after each block is what breaks the symmetry once the two halves stop lining up. This is why $w=0^p1$ (not $w=0^p$) is the right choice. The source also proves the near-identical language $\{w\#w\}$ by adapting the same proof.
>
> Related practice: `CSE331_pumping_lemma_exercises_solutions.pdf` #19 $\{ww \mid w \in \{a,b\}^*\}$ — same result over a two-letter alphabet, witness $a^nb^na^nb^n$.

## Closure Properties

**Class source:** whiteboard, ~24:29–25:45.

- If a language is **regular**, its complement is also **regular**.
- If a language is **non-regular**, its complement is also **non-regular**. (Contrapositive: if the complement were regular, closure under complement would make the original language regular too — contradiction.)

### Application: $E = \{\text{number of 0's and 1's are not equal}\}$ is Non-Regular

**Class source:** whiteboard, ~25:45.

$E = \overline{B}$ (the complement of $B$, proved non-regular above).

Since $B$ is non-regular, its complement $E$ is also non-regular — no separate pumping-lemma argument needed, this follows directly from the closure property above.

> **Info:** Secondary material (not from class) — this shortcut is a recognized standard technique
> `CSE331_pumping_lemma_rephrased_proofs.pdf` (TNF-shared, problem 3: $L=\{a^nb^l \mid n \neq l\}$) explicitly names this same move "an alternative and easier solution": *"The complement of a regular language should also be a regular language. So, if $\overline{L}$ is regular, $L$ will also be regular and vice versa... prove that $\overline{L}$ is not regular [first], only after [that] conclude that $L$ is also not regular."* That PDF's problem 3 is structurally the direct analogue of $E$: $\overline{L}=\{a^nb^l \mid n=l\}$ plays the role $B$ plays here. `CSE331_pumping_lemma_20_examples.md` (problem 2, "Equal number of 0's and 1's") makes the same general remark about using complement as a closure-property shortcut.
