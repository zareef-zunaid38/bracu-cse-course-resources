# CSE331 — Lecture 19: Decidability and Reducibility

Opens after [[CSE331_lecture_18_2026-08-31|Lecture 18]]'s $A_{TM}$-undecidability proof (page 1 of the scan opens mid-sentence, concluding that proof — already captured in Lecture 18's note). New material: the recognizable/co-recognizable characterization of decidability, $\text{HALT}_{TM}$'s undecidability, and reducibility as a proof technique — applied to $A_{NFA}$, $A_{REX}$ (decidable), $A_{TM}$ (undecidable, reduced from $\text{HALT}_{TM}$), $E_{TM}$ (undecidable, reduced from $A_{TM}$), and $E_{DFA}$ (decidable, bonus).

## Turing-recognizable vs. Turing-unrecognizable

Running a TM on $w$: if it accepts, it halts and $w \in L$. If it doesn't accept, it either rejects (halts, $w \notin L$) or loops forever (never halts, $w \notin L$). A language is **Turing-unrecognizable** when no TM is even guaranteed to halt and accept on strings that *are* in the language — i.e. no recognizer exists for it at all.

## Decidable = recognizable AND co-recognizable

- $A_{DFA}$ (DFA accepts the string) is recognizable — and so is its complement $\overline{A_{DFA}}$ (DFA doesn't accept it), since both can be checked by the same finite simulation that always halts.
- **Theorem (board statement):** when a language *and* its complement are both Turing-recognizable, the language is decidable.
- A language whose complement is Turing-recognizable is called **co-Turing-recognizable**.

This is the standard Sipser theorem ($L$ decidable $\iff$ $L$ and $\overline{L}$ both Turing-recognizable) and is the tool used next to show $\text{HALT}_{TM}$ is undecidable.

## $\text{HALT}_{TM}$ is undecidable

$\text{HALT}_{TM} = \{\langle M, w\rangle : M \text{ halts on } w\}$.

- $\text{HALT}_{TM}$ **is** Turing-recognizable: simulate $M$ on $w$; if $M$ halts (accept or reject either one), the simulator halts and accepts.
- $\overline{\text{HALT}_{TM}}$ (i.e. $M$ does *not* halt on $w$) is **not** recognizable: simulating $M$ can never confirm non-halting — $M$ might still be running, with no way to distinguish "will run forever" from "hasn't finished yet."
- Since $\overline{\text{HALT}_{TM}}$ isn't recognizable, by the theorem above $\text{HALT}_{TM}$ cannot be decidable (a decidable language's complement is always recognizable too).

**So $\text{HALT}_{TM}$ is not decidable.** This is the "known undecidable" starting point used below, and resolves the gap flagged in this note's first draft — $\text{HALT}_{TM}$'s undecidability was proved this lecture via the recognizable/co-recognizable theorem, not by diagonalization the way $A_{TM}$ was in Lecture 18.

## Reducibility — general idea

**Known vs. unknown outcome:** a decider always gives a known outcome (halts, accept or reject); a general TM/recognizer can leave the outcome unknown (may loop).

### Reduction — intuition first (from TNF's shared note, not on the board)

Simplest possible example: you want $\text{lcm}(a,b)$ but only know how to compute $\gcd(a,b)$. Use the identity $a \times b = \gcd(a,b) \times \text{lcm}(a,b)$ — compute the gcd, plug it into the formula, read off the lcm. You've just solved the lcm problem *by converting it into* a gcd problem. That conversion — take an input for problem $A$, transform it into an input for problem $B$, run $B$'s algorithm, transform the output back — is exactly what a reduction is. When this works, we write $A \le B$ ("$A$ reduces to $B$"), and the point is: $A$ is **no harder than** $B$, because a solution to $B$ hands you one for $A$ for free.

### Why the direction matters (from TNF's shared note)

You can't prove a problem unsolvable by exhaustion ("I tried for months and got nothing") — someone smarter might find the trick tomorrow. Reduction gives an actual proof: take a problem $D$ everyone already agrees is unsolvable, and convert *instances of $D$* into instances of the unknown problem $C$, arranged so that $C$'s answer tells you $D$'s answer. If $C$ were solvable, you could use it to solve $D$ — but $D$ is unsolvable, contradiction, so $C$ must be unsolvable too.

Going the other way — converting $C$ into $D$ — proves nothing: that would only show $C \le D$, i.e. $C$ is no harder than an unsolvable problem, which is true of *every* problem, easy ones included. So:
1. To prove **solvable**: convert the problem *into* a known-solvable one.
2. To prove **unsolvable**: convert a known-*unsolvable* problem *into* the problem.

Applied to decidability: to prove a language **decidable**, reduce it *to* an already-known-decidable language (used below for $A_{NFA}$, $A_{REX}$, $E_{DFA}$). To prove a language **undecidable**, reduce a *known-undecidable* language *into* it (used below for $A_{TM}$, $E_{TM}$) — never the reverse.

### The discipline: two questions every time (from TNF's shared note)

Every decidability-via-reduction proof below builds a machine that converts one problem's input into another's. Two things must be checked each time, or the proof has a hole in it:
1. **Does the conversion itself finish?** (halts in finite time, regardless of what it's fed)
2. **Does it preserve the answer?** (the converted instance is a "yes" exactly when the original was)

## Base case: $M_{DFA}$, the decider $A_{DFA}$ reduces to

$A_{DFA} = \{\langle D, w\rangle : D \text{ is a DFA that accepts } w\}$, decided by $M_{DFA}$ = "On input $\langle D, w\rangle$: simulate $D$ on $w$; if the simulation ends in an accept state, accept, else reject." The simulation always finishes after exactly $|w|$ steps, so $M_{DFA}$ never loops — it's a genuine decider, and every reduction below ultimately bottoms out here.

## $A_{NFA}$ is decidable

$A_{DFA}$ is decidable and trusted as known. Proof that $A_{NFA} = \{\langle N, w\rangle : N \text{ is an NFA that accepts } w\}$ is decidable — $M_{NFA}$ = "On input $\langle N, w\rangle$:"
1. Convert the NFA $N$ to an equivalent DFA $D$ via subset construction.
2. Simulate $D$ on $w$ (i.e. run $M_{DFA}$ on $\langle D, w \rangle$).
3. Since $L(D) = L(N)$, $D$ accepting $w$ means $N$ does too — so accept iff $M_{DFA}$ accepts.

Checked against the two-question discipline: **halts** — subset construction is a finite procedure (produces a DFA with at most $2^{|Q|}$ states, possibly large but finite, in finite time), and $M_{DFA}$ is itself a decider, so both steps terminate. **Preserves the answer** — subset construction guarantees $L(D) = L(N)$, so $\langle N,w\rangle \in A_{NFA} \iff w \in L(N) \iff w \in L(D) \iff \langle D,w\rangle \in A_{DFA}$, which is exactly what $M_{DFA}$ checks.

## $A_{REX}$ is decidable

Same pattern, one more step down: $M_{REX}$ converts the regular expression $R$ to an equivalent NFA $N$ via Thompson's construction, then runs $M_{NFA}$ on $\langle N, w\rangle$. **Halts** — Thompson's construction always terminates, giving an NFA linear in the length of $R$, and $M_{NFA}$ is a decider by the result just proved. **Preserves the answer** — Thompson's construction guarantees $L(N) = L(R)$, so $\langle R,w\rangle \in A_{REX} \iff \langle N,w\rangle \in A_{NFA}$.

## $A_{TM}$ is undecidable (reduction from $\text{HALT}_{TM}$)

**For contradiction:** assume $A_{TM}$ is decidable, with decider $R$.

Given $\langle M, w\rangle$, construct $M'$ that on any input $x$:
1. Runs $M$ on $w$.
2. If that run halts — whether $M$ accepts or rejects — $M'$ accepts $x$. (If $M$ never halts on $w$, $M'$ never halts on $x$ either.)

Constructing $\langle M' \rangle$ always halts — it is simply a fixed description built from $M$ and $w$.

So $L(M') = \Sigma^*$ if $M$ halts on $w$, else $L(M') = \varnothing$ — i.e. $L(M') = \Sigma^* \iff M$ halts on $w$.

Let $a$ be any string, and run $R$ on $\langle M', a\rangle$:

| $R$ on $\langle M', a\rangle$ | Meaning | Verdict for $\text{HALT}_{TM}$ on $\langle M, w\rangle$ |
|---|---|---|
| Accept | $M'$ accepts $a$ → $M$ halted on $w$ | **Accept** |
| Reject | $M'$ does not accept $a$ → $M$ did not halt on $w$ | **Reject** |

This would decide $\text{HALT}_{TM}$ — contradicting its undecidability above. So $R$ cannot exist: **$A_{TM}$ is not decidable.**

> [!note] Explanation
> This is a second, independent proof of Lecture 18's result — that lecture proved $A_{TM}$ undecidable directly by diagonalization; this one reduces from $\text{HALT}_{TM}$'s undecidability instead. The "constructing $M'$ always halts" line is the first of the two "does it halt / does it preserve the answer" checks from the Reducibility discipline above — it's easy to conflate "building the description of $M'$" with "running $M'$," and only the latter is actually in question. Any string $a$ works as the witness fed to $R$, since $M'$ ignores its own input entirely: $L(M')$ is either everything or nothing, never in between, so which specific $a$ you pick can't change the answer.

## $E_{TM}$ is undecidable (reduction from $A_{TM}$)

$E_{TM} = \{\langle M \rangle : L(M) = \varnothing\}$.

**For contradiction:** assume $E_{TM}$ is decidable, with decider $R$.

Given $\langle M, w \rangle$, construct $M'$ that on any input $x$:
1. Runs $M$ on $w$ (ignoring $x$).
2. If $M$ accepts $w$, $M'$ accepts $x$; if $M$ rejects $w$, $M'$ rejects $x$; if $M$ never halts on $w$, $M'$ never halts on $x$ either.

Constructing $\langle M' \rangle$ likewise always halts — a fixed description built from $M$ and $w$.

So $L(M') = \Sigma^*$ if $M$ accepts $w$, else $L(M') = \varnothing$ (reject or loop) — i.e. $L(M') \neq \varnothing \iff M \text{ accepts } w$.

Run $R$ on $\langle M' \rangle$:

| $R$ on $\langle M' \rangle$ | Meaning | Verdict for $A_{TM}$ on $\langle M, w\rangle$ |
|---|---|---|
| Reject | $L(M') \neq \varnothing$ | **Accept** — $M$ accepted $w$ |
| Accept | $L(M') = \varnothing$ | **Reject** — $M$ did not accept $w$ |

This would decide $A_{TM}$ — contradicting the result just above. So $R$ cannot exist: **$E_{TM}$ is not decidable.**

> [!note] Explanation
> Same halting-vs-running distinction as the $A_{TM}$ proof above applies to constructing $M'$ here. The original board diagram (a separate whiteboard photo, not in the notebook) used labels "accept → R" / "reject → A" and a "Halt/Loop" branch — these map onto the table above: $R$'s two outcomes determine $A_{TM}$'s verdict, and "Halt/Loop" is $M$'s behavior on $w$ inside $M'$, which is what makes $L(M')$ empty or not.

## $E_{DFA}$ is decidable — bonus, "for understanding only"

$E_{DFA} = \{\langle D \rangle : L(D) = \varnothing\}$. Sketch given: a DFA's states and transitions are stored on a tape as a finite table. Because the number of states is finite, you can algorithmically check whether any accepting state is *reachable* from the start state by tracing transitions through that finite table — if none is reachable, $L(D) = \varnothing$. The board illustrates this with a small worked automaton (state-reachability trace), explicitly marked as illustrative only, not exam-required — exact reachability marks on that diagram aren't reconstructed here since the note itself says not to rely on it. ## Anki

Q: What two properties together are equivalent to a language being decidable?
A: The language is Turing-recognizable AND its complement is Turing-recognizable (co-Turing-recognizable).

Q: Why is $\overline{\text{HALT}_{TM}}$ not Turing-recognizable, and what does that prove about $\text{HALT}_{TM}$?
A: Simulating $M$ on $w$ can never confirm non-halting (no way to distinguish "still running" from "will never halt"), so no recognizer for $\overline{\text{HALT}_{TM}}$ exists — since a decidable language's complement must be recognizable, $\text{HALT}_{TM}$ cannot be decidable.

Q: What must the direction of a reduction be to prove a language undecidable?
A: Reduce a *known* undecidable language *into* the unknown one — never the reverse.

Q: In the $A_{TM}$-via-$\text{HALT}_{TM}$ reduction, why does $M'$ accept $x$ whenever $M$ halts on $w$, regardless of whether $M$ accepted or rejected?
A: Because the question being answered is $\text{HALT}_{TM}$ (does $M$ halt on $w$ at all?), not $A_{TM}$ — so $M'$ only needs to signal "halted," collapsing accept/reject into one outcome and leaving only halt-vs-loop to distinguish $L(M') = \Sigma^*$ from $L(M') = \varnothing$.
