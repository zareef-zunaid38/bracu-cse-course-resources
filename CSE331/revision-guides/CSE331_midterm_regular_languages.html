📖 Theory ▼
Alphabets, Strings, Languages LOW

Alphabet $\Sigma$: a non-empty, finite set of symbols. String: a combination of symbols from one alphabet; $|w|$ = length. $\emptyset$ as a string is invalid — the valid zero-length string is $\varepsilon$ (empty string), $|\varepsilon|=0$. Language: the set of strings over $\Sigma$ satisfying some rule.

Substring = consecutive symbols from the string. Subsequence = symbols in order but not necessarily consecutive. $w^R$ = reverse of $w$.

Cluster-question fodder: "∅ is a valid string" — False. The valid empty string is ε, not ∅.
DFA — Deterministic Finite Automaton HIGH

5-tuple: $(Q, \Sigma, \delta, q_0, F)$ — $Q$ = states, $\Sigma$ = alphabet, $\delta$ = transition function, $q_0$ = start state, $F$ = accepting states.

Two defining properties: (1) every state must show a transition for every symbol in $\Sigma$ (no gaps — use a trap/dead state if needed); (2) from one state on one input, exactly one transition (no branching).

Common error (Assignment 1A, near-universal on Q1c): forgetting to enforce a "must be preceded by X" condition at the very start of the string — e.g. a string starting directly with the forbidden pattern should be rejected, but a naive DFA built from the middle-of-string logic outward often accepts it.
NFA — Nondeterministic Finite Automaton HIGH

Three defining properties (contrast with DFA): (1) only required transitions need to be shown; (2) one state + one input symbol can go to multiple states; (3) transitions on empty input ($\varepsilon$) are allowed.

NFAs are typically much smaller/cleaner for "contains substring", "third-to-last symbol", and union-type languages — the nondeterminism "guesses" the right branch.

Closure-normalization result: any NFA can be converted to an equivalent NFA with exactly one accepting state (add a new state, ε-transition every old accepting state into it, demote the old ones). This does not mean NFAs are restricted to one accepting state by definition — multiple accepting states are valid; this is only a normalization/closure construction. Known point of classmate confusion — do not overgeneralize it on a T/F cluster question.
Regular Operations: Union, Concatenation, Kleene Star HIGH

Union $L_1 \cup L_2$, Concatenation $L_1 . L_2$, Kleene Star $\Sigma^*$ = zero or more repetitions.

Cross Product Rule: to build a DFA for $L_1 \cup L_2$ or $L_1 \cap L_2$ from two component DFAs, take $Q_1 \times Q_2$ as the new state set and carry transitions over componentwise. Accepting states of the union = any pair containing an accepting state from either machine; for intersection, both components of the pair must be accepting.

Worked fact: intersecting two regular languages can legitimately give $\emptyset$ — e.g. all-0 strings ∩ odd-length all-1 strings share nothing (not even $\varepsilon$, since $\varepsilon$'s length 0 is even).
Closure Under the Regular Operations HIGH

Regular languages are closed under union, concatenation, and Kleene star — combining two regular languages with any of these operations always yields a regular language. Confirmed proof-of-correctness topics (generalized construction, no specific-example proof accepted):

  • Union: DFA cross-product construction, or the multi-path NFA argument (branch via ε into both component NFAs).
  • Concatenation: ε-transition from every accepting state of $M_1$ into the start state of $M_2$; only $M_2$'s accepting states remain accepting.
  • Kleene Star: ε-transition from every accepting state back to the start, plus a new start/accept state (or ε-edge to the old start marked accepting) to capture the zero-repetition case ($\varepsilon$).
Exam note (TNF, 2026-07-24): "Writing the correct method to the point will be enough" — explain how transitions/start/accepting states are constructed; full formal notation is not mandatory.
Format note (TNF, Discord, 2026-07-27): concatenation questions are normally expected as an NFA. A direct DFA for concatenation is only expected for the one specific pattern given in the assignment — for any other pattern, build the NFA; only convert to a DFA afterward if the question explicitly asks for one.
NFA→DFA: Subset Construction HIGH

Given an NFA with $n$ states, build an equivalent DFA whose states are subsets of the NFA's states.

  1. Compute the ε-closure of every state (the set of states reachable via ε-transitions only, including itself).
  2. Start state of the DFA = ε-closure of the NFA's start state.
  3. For each reachable subset $S$ and symbol $a$: $\delta_{DFA}(S,a) = \bigcup_{q\in S}\varepsilon\text{-closure}(\delta_{NFA}(q,a))$.
  4. A subset-state is accepting iff it contains at least one of the NFA's original accepting states.
  5. Only build subsets actually reachable from the start — do not enumerate the full power set.

Bound: max DFA states = $2^n$. Max accepting subset-states = $2^n - 2^{n-k}$ where $k$ = number of NFA accepting states (subsets that miss all $k$ marked states = $2^{n-k}$, so the rest, $2^n-2^{n-k}$, must contain at least one).

Confirmed scope: only the NFA→DFA direction is examinable this Mid-Term — do not prepare DFA→NFA.
Regular Expressions MED

A combination of symbols and the three regular operations describing exactly the strings in a language. Core identities:

  • $R\cdot\varepsilon = R$ — ε is the concatenation identity.
  • $R\cdot\emptyset = \emptyset$ — ∅ absorbs under concatenation.
  • $R+\emptyset = R$ — ∅ is the union identity.
  • $R+\varepsilon = R+\varepsilon$ — does not simplify further in general (only reduces to $R$ if $\varepsilon \in L(R)$ already).
Most frequent class-wide mistake (Assignment 1B + Quiz 2 grading feedback): wrapping the entire expression in a Kleene star when only a sub-part needed it — silently breaks constraints like "guarantee an odd number of 0s after the last 1."
Equivalence of Regular Expressions and Finite Automata HIGH

Every regular expression has an equivalent FA, and vice versa. Two confirmed constructions:

  • RE → NFA (Thompson's Construction): build small NFA fragments for each RE piece (single symbol, union, concatenation, star) and wire them together with ε-transitions. A single-symbol Kleene star ($b^*$) can be drawn either via the full ε-based detour, or as a shortcut: one state entered by a $b$-transition with a self-loop on $b$, usable as both entry and exit (covers zero, one, or more $b$'s from that single state).
  • FA → RE (state elimination / GNFA): see the dedicated concept below — this is the confirmed, sole accepted method.
Confirmed acceptable (TNF, Discord, 2026-07-27/28): the self-loop shortcut for a starred term is fine even when it's only part of a larger expression — e.g. for $b(a{+}c)^*$, draw the one required $b$-edge, then connect via ε into a self-loop-shortcut state for $(a{+}c)^*$ (self-looping on both $a$ and $c$); concatenation is carried by that connecting ε-edge. Also confirmed: $(a{+}b)^+$ may be drawn as $(a{+}b)(a{+}b)^*$ — one required copy followed by the starred remainder.
DFA → RE via State Elimination (GNFA Method) HIGH

Pipeline: DFA → NFA → GNFA (a Generalized NFA — edges can carry a full regex, not just a symbol/ε).

Step 1 — reshape into GNFA form:

  1. Start state must have no incoming edges — if it does, add a new start state with a single ε-edge into the old one.
  2. Exactly one accepting state — if there are several, add one new accepting state, ε-edge every old accepting state into it, demote the old ones.
  3. The accepting state must have no outgoing edges — if it does, demote it and add an ε-edge to a fresh accept state with no outgoing edges.

Step 2 — eliminate states one at a time (any order, but note it in your answer). Eliminating state $q$: for every incoming state $p$ and outgoing state $r$, replace with

State elimination formula
$new\_label(p,r) = old\_label(p,r) \;\cup\; label(p,q)\cdot label(q,q)^*\cdot label(q,r)$
If $q$ has no self-loop, $label(q,q)^* = \varepsilon$ (drops out). Edges not routed through $q$ are carried over unchanged.

Stop when only start and accept remain — the label on that final edge is the answer.

Main source of lost marks class-wide (Quiz 2 + Assignment 1B, same error both times): when eliminating a state, only that state's own self-loop feeds the new transition. Self-loops on states not being eliminated must never be pulled in — only two paths feed each new edge: the direct $(p,r)$ path, and the path routed through $q$.
Method rule (TNF, confirmed 2026-07-26 — overrides the one-time Quiz 2 leniency): state elimination is the only accepted method. State equations / Arden's Theorem will not be accepted on the Mid-Term, even partially.
Additional rules (TNF, Discord, 2026-07-24 to 2026-07-28):
  • A self-loop on the start state counts as an incoming edge — Rule 1 still applies even if the only edge into the start state is its own self-loop; a new start state must still be added.
  • Preprocessing doesn't have to happen all upfront. If the state you need to eliminate next turns out to be the current start or an accepting state, add the new start/accept state at that point instead of upfront. The only hard requirement: by the end, exactly two states remain — the new start and the new accept.
  • If the state being eliminated has no incoming edge or no outgoing edge, delete it outright — do not apply the elimination formula. No incoming/outgoing edge means no string can ever be accepted through it, so nothing needs to be preserved.
❓ Short Questions ▼

Tap a question to reveal the answer. Try to recall first.

What are the two defining properties of a DFA, and the three of an NFA?HIGH
DFA: (1) every state shows a transition for every input symbol, (2) exactly one resulting state per (state, symbol) pair. NFA: (1) only required transitions shown, (2) one (state, symbol) pair can go to multiple states, (3) ε-transitions allowed.
What is the ε-closure of a state, and why is it computed before subset construction?HIGH
The set of all states reachable from it using only ε-transitions (including itself). It's needed because after taking a real symbol transition, the DFA state must also include everything reachable "for free" via ε before the next symbol is read — otherwise reachable NFA states get silently dropped.
If an NFA has n states and k accepting states, what's the max number of DFA states and max number of accepting DFA states after subset construction?HIGH
Max total: 2ⁿ (the full power set). Max accepting: 2ⁿ − 2ⁿ⁻ᵏ (all subsets except those that miss every one of the k accepting states). The actual DFA is often smaller since only reachable subsets are kept.
What three conditions must a GNFA satisfy before state elimination can begin?HIGH
(1) Start state has no incoming edges, (2) exactly one accepting state, (3) that accepting state has no outgoing edges — adding new ε-connected start/accept states as needed to enforce this.
When eliminating state q, which self-loops are allowed to appear in the new formula?HIGH
Only q's own self-loop (label(q,q)), starred. Self-loops on any other state must never be folded into the new edge — that's the single most common Mid-Term-relevant error seen on Quiz 2 and Assignment 1 Part B.
Which regex identity does NOT simplify further in general: R·ε, R·∅, R+ε, or R+∅?MED
R+ε — stays as R+ε unless ε ∈ L(R) already. Contrast with R+∅=R (∅ is the union identity) and R·ε=R, R·∅=∅ (concatenation identity/absorber).
State De Morgan's Law for regular languages.MED
Complement of union = intersection of complements: ‾(A∪B) = Ā∩B̄. Complement of intersection = union of complements: ‾(L₁∩L₂) = L̄₁∪L̄₂. Useful for solving "complement of a set-combination" without re-deriving from scratch — reduce to complements you've already found.
Difference between a substring and a subsequence?LOW
Substring: consecutive symbols from the string. Subsequence: symbols in the same order but not necessarily consecutive.
Express set difference L₁ \ L₂ using intersection and complement.LOW
L₁ \ L₂ = L₁ ∩ complement(L₂).
Does every NFA have to have at most one accepting state?MED
No. Multiple accepting states are valid by definition. There's a separate proof that any NFA can be converted to an equivalent one with a single accepting state (via a new ε-joined accept state) — that's a closure/normalization result, not a restriction on NFAs in general. This is a known point of confusion — watch for it on a T/F cluster question.
🧮 Analytical Questions ▼
Q1 Convert this NFA to an equivalent DFA using subset construction. NFA: q1 →ε→ q2, q1 →a→ q4, q4 →a→ q2, q4 →b→ q3, q2 →ε,b→ q3, q3 →a→ q3 (self-loop), q3 accepting. HIGH ▼
1
Compute ε-closures first: closure(q1) = {q1,q2,q3} (q1→q2 via ε, q2→q3 via ε). closure(q2) = {q2,q3}. closure(q3) = {q3}. closure(q4) = {q4} (no ε-edges out of q4).
2
Build the NFA transition table using these closures: from q1 on 'a' → {q4}; from q2 on 'b' → {q3}; from q3 on 'a' → {q3} (self-loop). q3 is the only original accepting state.
3
DFA start state = closure(q1) = {q1,q2,q3} — call it A. Since A contains q3, A is accepting.
4
From A on 'a': union of closures of NFA-moves on 'a' from {q1,q2,q3} → q1 moves to q4, q2/q3 have no 'a' move except q3→q3 → result {q3,q4} = state B (accepting, contains q3). From A on 'b': only q2→q3 → {q3} = state C (accepting).
5
From B={q3,q4} on 'a': q3→q3, q4→q2 → {q2,q3} = state D (accepting). From B on 'b': q3 has no b, q4→q3 → {q3} = C.
6
From C={q3} on 'a': {q3}=C. On 'b': ∅ = trap (non-accepting, dead). From D={q2,q3} on 'a': q3→q3 → {q3}=C. On 'b': q2→q3, q3 none → {q3}=C.
7
Final DFA: 5 states {A(start,acc), B(acc), C(acc), D(acc), trap}. Every reachable subset containing q3 is accepting — which is every one of them here except the trap.
Key insight: stop as soon as no new subsets appear on either input from any state you've already built — do not enumerate the full 2⁴=16-state power set, only what's reachable.
Exam note: only NFA→DFA is confirmed examinable. Mark every accepting subset explicitly — TNF's feedback flagged "counted non-accepting subsets as accepting" as the single most common Q3-type error on Assignment 1A.
Q2 Convert this DFA to a regular expression via state elimination. States 1(start),2,3 both 2 and 3 accepting: 1→a→2, 1→b→3, 2→a→1, 2→b→2(self-loop), 3→a→2, 3→b→1. HIGH ▼
1
Preprocess into GNFA: two accepting states (2, 3) → add new accept state f, ε-edge from 2 to f and from 3 to f, demote 2 and 3. Add new start state 6 with ε-edge into 1 (1 already has no incoming edges, but adding a fresh start is the safe default). GNFA: 6→ε→1, 1→a→2, 1→b→3, 2→a→1, 2→b→2(self), 2→ε→f, 3→a→2, 3→b→1, 3→ε→f.
2
Eliminate state 2. Incoming to 2: {1 via a, 3 via a}. Outgoing from 2: {1 via a, f via ε}. Self-loop on 2: b. New edges — (1,1): a·b*·a = ab*a. (1,f): a·b*·ε = ab*. (3,1): old(b) ∪ a·b*·a = b + ab*a. (3,f): old(ε) ∪ a·b*·ε = ε + ab*. The direct 1→b→3 edge is untouched (doesn't route through 2).
3
Resulting 3-state GNFA (start, 1, 3, f): 1 self-loop ab*a; 1→f: ab*; 1→3: b (unchanged); 3→1: b+ab*a; 3→f: ε+ab*.
4
Eliminate state 3. Incoming to 3: {1 via b}. Outgoing from 3: {1 via b+ab*a, f via ε+ab*}. No self-loop on 3 (label(3,3)*=ε). New edges — (1,1) self-loop: old(ab*a) ∪ b·ε·(b+ab*a) = ab*a + b(b+ab*a). (1,f): old(ab*) ∪ b·ε·(ε+ab*) = ab* + b(ε+ab*).
5
Eliminate state 1 (last internal state) — collapses directly to a single start→accept edge labeled with the final RE.
Final Regular Expression
$(ab^*a+b(b+ab^*a))^*\,(ab^*+b(\varepsilon+ab^*))$
Key insight: notice every combined label at each step is exactly old_label ∪ (path through the eliminated state) — never anything more. Track incoming/outgoing pairs of the state being eliminated methodically; don't try to do it by eyeballing the diagram.
Exam note: show the GNFA diagram after each elimination step — TNF's Quiz 2 rubric required this explicitly. State the elimination order you chose.
Q3 Prove, in generalized form, that regular languages are closed under concatenation and under Kleene star. HIGH ▼
1
Concatenation: given NFA $M_1$ for $L_1$ and $M_2$ for $L_2$, add an ε-transition from every accepting state of $M_1$ into the start state of $M_2$. Demote $M_1$'s accepting states to non-accepting; only $M_2$'s original accepting states remain accepting in the combined machine.
2
Any string accepted by the combined machine must first traverse $M_1$ to reach one of its (now ε-connected) accepting states, then continue through $M_2$ to one of its accepting states — exactly the strings of the form $xy$ with $x\in L_1, y\in L_2$, i.e. $L_1.L_2$.
3
Kleene star: given NFA $M$ for $L$, add a new start/accept state $q_0'$ with an ε-edge to $M$'s original start (to allow zero repetitions — accepting $\varepsilon$ directly), and add ε-edges from every one of $M$'s accepting states back to $M$'s original start (to allow repeating).
4
Any string accepted is either ε (via the direct ε-edge) or a concatenation of one-or-more strings each individually in $L$, since each pass through $M$ must end at an accepting state before looping back — exactly $L^*$.
Exam note (TNF, confirmed): a proof by a specific example language is explicitly not accepted — always frame the answer as "given any NFA(s) for the operand language(s), construct ... " in general terms. No need for full formal notation; explaining the construction idea is sufficient.
Q4 Design a DFA: non-empty strings over {0,1} where at most two consecutive 0's are allowed, and any occurrence of "00" must have at least one 1 immediately before it and at least one 1 immediately after it. MED ▼
1
This was the single most-missed sub-question on Assignment 1 Part A — treat it as a template for "constraint must hold from position 1" traps, not this exact language.
2
Design states tracking: how many consecutive 0's seen right now (0/1/2), and whether a 1 has been seen immediately before entering the current 0-run. A string that starts directly with "00" must be rejected — there is no 1 before it.
3
Sanity-test before finalizing: does the DFA reject 001, 0011, 00 (all missing a leading 1)? Does it accept 1001, 10011?
4
Also verify: no state has zero incoming edges unless it's the start state — a stray state with no logical path in usually means the structure was invented rather than derived from the constraint.
Common errors seen on this exact question type (TNF feedback): wrong transition on 0 from the start states (the "at least one 1 before" condition silently dropped), a disconnected extra state, missing double-circles on accepting states, accepting a string that starts with "00".
Q5 Write a regular expression for strings over {0,1} that do not contain "111" as a substring. MED ▼
1
Build the language as repeated "safe blocks," each of which cannot end in enough 1's to combine with the next block into "111": blocks are 0, 10, or 110 — every block ends in a 0, so no block-boundary can ever create three consecutive 1's.
2
Repeat those blocks zero or more times: $(0 \cup 10 \cup 110)^*$.
3
Allow the string to end mid-way through a run of 1's, as long as it's still fewer than three: trailing term $(\varepsilon \cup 1 \cup 11)$.
Result
$(0 \cup 10 \cup 110)^*(\varepsilon \cup 1 \cup 11)$
Key insight (generalizes to "doesn't contain 1ⁿ" for any n): pick block boundaries that always end in 0, so no legal concatenation of blocks can ever create the forbidden run across a boundary — then add a bounded trailing term for the partial run at the very end.
∑ Formula & Pattern Cheat Sheet ▼
Subset Construction Bound
$|Q_{DFA}| \le 2^n \qquad |F_{DFA}| \le 2^n - 2^{n-k}$
n = # NFA states, k = # NFA accepting states. Only reachable subsets are actually built.
State Elimination Formula
$new(p,r) = old(p,r) \cup label(p,q)\cdot label(q,q)^*\cdot label(q,r)$
q = state being eliminated. If q has no self-loop, label(q,q)* = ε.
Regex Identities
$R\cdot\varepsilon = R \qquad R\cdot\emptyset = \emptyset \qquad R+\emptyset = R \qquad R+\varepsilon \ne R \text{ (in general)}$
De Morgan's for Regular Languages
$\overline{A \cup B} = \bar{A} \cap \bar{B} \qquad \overline{L_1 \cap L_2} = \bar{L_1} \cup \bar{L_2}$
Length-Based Regex Patterns (Σ = alphabet)
even: $(\Sigma\Sigma)^*$ odd: $\Sigma(\Sigma\Sigma)^*$ mult. of 3: $(\Sigma\Sigma\Sigma)^*$ exactly n: $\Sigma^n$ ≥n: $\Sigma^n\Sigma^*$ ≤n: $\varepsilon\cup\Sigma\cup\dots\cup\Sigma^n$
Count-Based Regex Patterns (over {0,1})
exactly 3 zeros: $1^*01^*01^*01^*$ at least 3 zeros: $\Sigma^*0\Sigma^*0\Sigma^*0\Sigma^*$ at most 3 zeros: $1^*\cup1^*01^*\cup1^*01^*01^*\cup1^*01^*01^*01^*$
Starts/Ends Symmetric Patterns
starts & ends same symbol: $0\Sigma^*0 \cup 1\Sigma^*1 \cup 1 \cup 0$ doesn't contain 11: $(0\cup10)^*(1\cup\varepsilon)$ alternating 0/1: $(\varepsilon\cup1)(01)^*(\varepsilon\cup0)$

🧠 Mnemonics & Memory Aids ▼
"Only q's own loop"
State elimination: the new edge formula only ever uses the self-loop of the state being eliminated, never any other state's self-loop. This one line prevents the #1 recurring class-wide error.
"No In, One Out-less Accept"
GNFA shape rules: start has No incoming edges; exactly One accepting state; that accept state has no Outgoing edges. (New start/accept states added with ε if the original doesn't already satisfy this.)
"Reachable, not the whole power set"
Subset construction: 2ⁿ is only the ceiling. Build outward from the start's ε-closure and stop once no new subset appears — don't pre-enumerate everything.
"∅ disappears, ε doesn't"
Regex identities: R·∅=∅ and R+∅=R (∅ vanishes both ways). But R+ε stays R+ε — ε is NOT automatically absorbed into a union unless it was already in the language.
