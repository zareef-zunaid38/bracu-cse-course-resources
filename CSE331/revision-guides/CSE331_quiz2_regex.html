📖 Theory ▼
Regular Expression — Definition & Operators HIGH

A regular expression is a combination of symbols and operations (union, concatenation, Kleene star) that defines exactly the strings belonging to a language.

  • Union (∪ or +): either operand.
  • Concatenation: operands back-to-back.
  • Kleene star (*): zero or more repetitions.
  • Σ = any single symbol; Σ* = any string including ε; Σ⁺ = ΣΣ* = any string of length ≥ 1.
Common RE Pattern Cheat Sheet HIGH

Length constraints (over Σ={0,1}):

  • Even length: (ΣΣ)*  |  Odd length: Σ(ΣΣ)*
  • Multiple of n: (Σ…Σ)* (n copies of Σ)
  • Length = kn+r: Σ^r (Σ^n)*
  • Length ≥ n: Σ^n Σ*  |  Length ≤ n: ε ∪ Σ ∪ ΣΣ ∪ … ∪ Σ^n (explicit union, no shortcut)

Substring / symbol-count constraints:

  • Contains substring w: Σ*wΣ*
  • Contains exactly k 0's: 1*01*01*…01* (k copies of 01*, one leading 1*)
  • Doesn't contain 11: (0∪10)*(1∪ε)
  • Ends with 01 or 10: Σ*(01∪10)
Complement of a Regular Language & De Morgan's Law MED

To build a complement RE, don't negate term-by-term — re-derive from the opposite condition (e.g. "length ≥ n" complements to "length ≤ n−1", not "length < n" written loosely).

Watch ε carefully: if ε is excluded from L (e.g. "starts and ends with same symbol" requires two symbols to compare), it must be explicitly added back into the complement, since ε trivially fails the original condition.

A ∪ B = A̅ ∩ B̅   |   L₁ ∩ L₂ = L̅₁ ∪ L̅₂
GNFA & State Elimination (FA → RE) HIGH

A GNFA (Generalized NFA) allows transition labels to be entire regular expressions, not just single symbols/ε. Converting a DFA/NFA to a GNFA and eliminating states one at a time down to just start→accept produces an equivalent RE.

Required GNFA shape before elimination starts:

  1. Start state has no incoming edges — add a new start state with an ε-edge into the old one if needed.
  2. Exactly one accepting state — merge multiple accept states into one via ε-edges if needed.
  3. The accepting state has no outgoing edges — demote it and add an ε-edge to a fresh, exit-free accept state if needed.
Common error: Forgetting to check all three preprocessing conditions before starting elimination — a DFA with a self-loop on the accept state, for instance, needs the fresh accept-state step.
RE → NFA (Thompson's Construction) LOW — likely out of scope

Opposite direction of this quiz's stated syllabus ("FA to Regular Expression"). Thompson's construction builds an NFA from an RE using ε-transition scaffolding per operator (union, concatenation, star). Know it exists and roughly how union/star fragments are wired, but do not spend prep time drilling it for Quiz 2 unless the syllabus is confirmed to include it — it is, however, tested on Assignment 1 Part B.

❓ Short Questions ▼

Tap a question to reveal the answer. Try to recall first.

What are the three conditions a GNFA must satisfy before state elimination begins? HIGH
(1) Start state has no incoming edges. (2) Exactly one accepting state. (3) The accepting state has no outgoing edges. Add new ε-connected start/accept states as needed to force this shape.
Write the general formula for the new edge label when eliminating state q between states p and r. HIGH
new_label(p,r) = old_label(p,r) ∪ label(p,q)·label(q,q)*·label(q,r) — the existing direct edge, unioned with the path that detours through q and loops on q's self-label zero or more times.
When does the state elimination process stop, and what is the final answer? HIGH
When only the start and accept states remain (every other state eliminated one at a time). The label on the final start→accept edge is the resulting regular expression.
Write a regular expression over {0,1} for "length is even." HIGH
(ΣΣ)* — pair symbols two at a time, any number of pairs including zero.
Write a regex for "doesn't contain 11" over {0,1}. MED
(0∪10)*(1∪ε) — repeating the block (0∪10) can never produce two consecutive 1's, since every 1 immediately starts a new block.
State De Morgan's Law for regular languages. MED
A̅∪B̅ from A∩B — i.e. complement(A∪B) = complement(A)∩complement(B), and complement(L₁∩L₂) = complement(L₁)∪complement(L₂). Same as set De Morgan's, applied directly.
Which RE identity does NOT simplify further in general: R·ε, R·∅, R+ε, or R+∅? MED
R+ε — it stays as R+ε unless ε∈L(R) already. Contrast with R+∅=R (∅ is the union identity) and R·ε=R, R·∅=∅ (concatenation identity/absorber).
What is a GNFA and how does it differ from a regular NFA? LOW
A Generalized NFA — its transitions can be labeled with entire regular expressions instead of just single symbols or ε. Used as an intermediate structure for converting a DFA/NFA into an RE via state elimination.

Q1 Convert the given DFA to a regular expression using the GNFA state-elimination method. (Lecture 9 worked example — the closest known analogue to what Quiz 2 will ask.) HIGH ▼
Original DFA — start: 1, accept: 3, Σ={a,b} 1 --a--> 2 2 --b--> 2 (self-loop) 2 --a--> 1 1 --b--> 3 3 --a--> 1 3 --b--> 3 (self-loop)
1
Preprocess into GNFA form. Add new start state 6 with 6 --ε--> 1 (old start already has incoming edges from state 3, so this is required). Add new accept state f with 3 --ε--> f, since state 3 currently has outgoing edges and can't remain the accept state.
2
Eliminate state 2 (order used: 2, 3, 1). Incoming to 2: {1,3}. Outgoing from 2: {1,f}. Apply the formula to each of the 4 pairs (1,1), (1,f), (3,1), (3,f):
1→1: ab*a  |  1→f: ab*  |  3→1: b ∪ ab*a  |  3→f: ε ∪ ab*
3
Eliminate state 3. Only state 1 remains as an internal state. Fold state 3's self-loop (b) and its edges into 1's self-loop and 1→f edge:
1→1 (self-loop): ab*a ∪ b(b ∪ ab*a)  |  1→f: ab* ∪ b(ε ∪ ab*)
4
Eliminate state 1 (last internal state). This collapses directly to a single start→accept edge labeled with the final RE — apply the self-loop as a Kleene star prefix, then the direct edge.

Step 3 then reuses those labels as if they run 1→3, which is inconsistent with how they were transcribed in step 2. Q2 Write a regular expression for: strings over {0,1} where the first and third symbols are the same (if they exist). Then write the complement. HIGH ▼
1
Handle the two matching cases separately: first=third=0, or first=third=1. Pattern: 0 Σ 0 Σ* and 1 Σ 1 Σ* (fixed 1st/3rd symbol, free 2nd symbol, free tail).
2
Add the vacuous cases — strings too short to have a 3rd symbol still satisfy "if they exist": ε ∪ Σ ∪ ΣΣ (lengths 0, 1, 2).
3
Full RE: 0Σ0Σ* ∪ 1Σ1Σ* ∪ ε ∪ Σ ∪ ΣΣ.
4
Complement: only strings of length ≥ 3 where first ≠ third are excluded — 0Σ1Σ* ∪ 1Σ0Σ*. The short-string terms (ε, Σ, ΣΣ) drop out entirely since they were already included on the "true" side.
Key insight: "If they exist" clauses always need an explicit short-string union — this is the exact trap tested in Quiz 1 (Q2b: "first and third positions contain the same symbol, if they exist").
∑ Formulas & Identities ▼
State Elimination Rule
new(p,r) = old(p,r) ∪ label(p,q)·label(q,q)*·label(q,r)
Where q is the state being eliminated; p, r are its neighbors (p can equal r for a self-loop result). Apply once per (p,r) pair reachable through q.
RE Identities (concatenation / union identities)
R·ε = R R·∅ = ∅ R+∅ = R R+ε = R+ε (no further simplification)
ε is the concatenation identity; ∅ is absorbing under concatenation and is the union identity. R+ε only reduces to R if ε∈L(R) already.
De Morgan's Law (regular languages)
complement(A∪B) = complement(A) ∩ complement(B) complement(L1∩L2) = complement(L1) ∪ complement(L2)
Directly inherited from set-theoretic De Morgan's — applies to regular expressions/languages without modification.

🧠 Mnemonics & Memory Aids ▼
"In, Loop, Out"
State elimination formula, recalled in plain order: new(p,r) = old(p,r) ∪ in(p→q) · loop(q→q)* · out(q→r).
"One In, One Out"
GNFA preprocessing checklist: start has no edges IN, accept has no edges OUT, and there's only ONE accept state.
"If they exist ⇒ add the short ones"
Any positional RE condition ("if they exist") needs an explicit union of the too-short-to-apply cases (ε, Σ, ΣΣ, …) — the exact trap in Quiz 1's Q2b.
