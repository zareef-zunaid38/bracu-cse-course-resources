**Q1.** Which of the following statements about regular expressions is true?
- Regular expressions can describe only Regular Languages.
- Regular expressions can describe only Context Free Languages.
- Regular expressions can describe both Regular Language and Context Free Languages.

**Q2.** Which is the correct regular expression for the language L = {w ∈ {0,1}\*: 0ⁿ, where n is even}?
- 0 (00)*
- (00)*

**Q4.** You are given two languages, A and B. You can construct a regular expression for A. However, it is impossible to construct a regular expression for B. Now read the options below:
a) A is a regular language
b) B is a regular language
c) B is a nonregular language
d) A∪B is a regular language

Choose the best answer:
- a and b
- a and c
- a and d
- a, b and d
- a, c and d

**Q9.** Let Σ = {a, b}. You are given a regular expression: a(Σ\* a⁺ ε) ∪ b(Σ\* b⁺ ε), where a⁺ = aa\*.

What is the correct language for this regex?

a) w starts and ends with the same symbol
b) w contains either at least two a or at least two b
c) w contains substring ab
d) w contains an a followed by a b
e) w contains equal numbers of ab and ba

Choose the best answer:
- a
- a and b
- c and d
- a and e
- a, b and e

*(Note: for a regular language L, the regular expression is correct iff it generates all strings w ∈ L and no string w ∉ L.)*

**Q10.** Which of the following regular expressions are equivalent to a(a\* b\* ∪ b⁺)b ?
a) a⁺(ab⁺)
b) a\*(ab⁺)
c) a⁺b⁺
d) a(aa\*b\*)b
e) a\*(a\*b⁺ ∪ b\*)b

Choose the best answer:
- a and b
- c and d
- d and e
- b and c

**Q13.** Let Σ = {0,1}. What is the regular expression for the strings that have even length and start with 1?

**Q14.** L = {w ∈ {0,1}\*: w doesn't contain 001}

*(Note: for a regular language L, the regular expression is correct iff it generates all strings w ∈ L and no string w ∉ L.)*

Which of the following regular expressions generate L? (mark each Correct/Incorrect independently)
- (1\* (01)\*)\* (ε ∪ 0 ∪ 000\*)
- (1\* (0 ∪ ε) 1\*)\*
- (1 ∪ 10)\* (ε ∪ 0 ∪ 000\*)
- (1 ∪ 01)\* 0\*
- (1\* (10)\*)\* 0\*

**Q15.** (0 ∪ ε)(10)\*(1 ∪ ε)

*(Note: for a regular language L, the regular expression is correct iff it generates all strings w ∈ L and no string w ∉ L.)*

Which of the following regular languages are generated by the given regular expression? (mark each Correct/Incorrect independently)
- L = {w ∈ {0,1}\*: w doesn't contain 00}
- L = {w ∈ {0,1}\*: 0 and 1 alternate in w}
- L = {w ∈ {0,1}\*: w doesn't contain either 00 or 11}
- L = {w ∈ {0,1}\*: the period of w is either 01 or 10}

*(The period of a string is the smallest prefix which, when repeated one or more times, recreates the entire string.)*
