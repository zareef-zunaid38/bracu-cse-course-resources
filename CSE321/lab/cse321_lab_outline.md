# CSE 321: Operating Systems Laboratory Outline

Laboratory activity plan, assessments, assignments, term project, grading policies, and attendance requirements for CSE321 Lab (Summer 2026).
Docx last modified: 27-06-2026.

## Content

### Course Description
Familiarization with Linux terminal, C programming, process management, thread concepts and management, thread synchronization, xv6 OS codebase, OS-level user programs in xv6, system call implementation in xv6, preemptive process scheduling in xv6, and Inter-Process Communication (IPC).

### Lab Activity Plan
- **Class 0 (Weeks 1–2, 9 June – 18 June)**: Basic Shell Commands, Basic C Programming (buX online self-study tutorials).
- **Class 1 (Week 3, 20 June – 25 June)**: System Calls (C system calls for process manipulation, file descriptors, performance profiling, tracing).
- **Class 2 (Week 4, 27 June – 2 July)**: Linux Shell Scripting (Bash automation, user input, CLI arguments).
- **Class 3 (Week 5, 4 July – 9 July)**: Assessment 1 (Basic shell commands & C programming from buX self-study; 7 marks).
- **Class 4 (Week 6, 11 July – 16 July)**: Threads and Synchronization (pthreads, mutex, semaphore, race condition solutions).
- **Class 5 (Week 7, 18 July – 23 July)**: IPC (pipes, shared memory, message passing).
- **Weeks 8–9 (25 July – 6 Aug)**: Mid-Week — No Lab.
- **Class 6 (Week 10, 8 Aug – 13 Aug)**: xv6 - Introduction (installation tutorial, booting process, kernel vs user space, file system hierarchy, user programs; Wed 9 Aug in-person / Sun 14 Aug online make-up).
- **Class 7 (Week 11, 15 Aug – 20 Aug)**: xv6 - Features (system call implementation & tracing, process structure, context switching, scheduler control, preemptive scheduling; Wed 12 Aug in-person).
- **Class 8 (Week 12, 22 Aug – 27 Aug)**: Assessment 2 (System calls, threads and synchronization covered in Labs 1 and 4; 7 marks; Wed 19 Aug in-person).
- **Class 9 (Week 13, 29 Aug – 3 Sep)**: Review & Project Viva.

### Grading Policies & Assessment Schedule
- **Attendance Policy**: 90% lab attendance is mandatory to attend the final exam.
- **Honor Code**: Plagiarism or academic dishonesty results in an "F" grade (or 0 marks for that assessment).
- **Lab Assignments (8 Marks Total)**:
  - Submission via Google Forms. 1 mark deducted per day of late submission.
  - *Assignment 1 (Week 6, 1 week deadline)*: Threads and Synchronization — **3 Marks**
  - *Assignment 2 (Week 11, 1 week deadline)*: xv6 Process Scheduling — **5 Marks**
- **Lab Assessments (7 Marks Total)**:
  - Average of n assessments. No make-ups.
  - *Assessment 1 (Week 5)*: Basic C Programming & Bash Commands — **7 Marks**
  - *Assessment 2 (Week 12)*: System Calls, Threads & Synchronization — **7 Marks**
- **Term Project (10 Marks Total)**:
  - Group project centrally published on Slack with identical deadlines across all sections.
  - *Term Project 1 (Week 10, 2 weeks deadline)*: Topic TBA — **10 Marks** (Separate marks for implementation and viva; no late submissions or make-up vivas).
