# Implementing a Priority Scheduler in xv6

Lab guide and implementation steps for replacing xv6's round-robin scheduler with a strict priority-based scheduler and adding the setpriority system call.
Docx last modified: 17-08-2026.

## Content

### Overview & Objectives
Modifies the default round-robin scheduler of xv6 to implement a strict priority scheduler where each process is assigned a priority integer from `1` (highest priority) to `10` (lowest priority).
Key steps covered:
- Introducing priority and turn-tracking fields to `struct proc`
- Setting priorities from user space via a new system call (`setpriority`)
- Ensuring children inherit parent priority on `fork()`
- Modifying the scheduler loop to strictly select the highest-priority runnable process
- Updating `procdump` (Ctrl+P) to print priority and execution turn counts
- Testing scheduler behavior with background test programs

---

### Step 1 — Add Fields to `struct proc`
Open `kernel/proc.h` and add `priority` and `rounds` fields to `struct proc`:
```c
struct proc {
  // ... existing fields ...
  int priority;   // 1 = highest, 10 = lowest
  int rounds;     // how many times the scheduler has run this process
};
```

---

### Step 2 — Initialize Priority and Turns
Modify `allocproc()` in `kernel/proc.c`:
```c
p->priority = 10;   // default lowest priority
p->rounds = 0;
```
Special rule for initial process in `userinit()` (`kernel/proc.c`):
```c
p->priority = 1;
```
Ensures xv6 boots reliably with highest priority for the init process.

---

### Step 3 — Make Children Inherit Parent Priority
Modify `kfork()` / `fork()` in `kernel/proc.c`:
```c
np->priority = p->priority;
np->rounds = 0;
```
Maintains consistent priorities across parent and child processes.

---

### Step 4 — Create `setpriority` System Call
System call signature: `int setpriority(int newprio);`

1. **User space declaration** (`user/user.h`):
   ```c
   int setpriority(int);
   ```
2. **Syscall number** (`kernel/syscall.h`):
   ```c
   #define SYS_setpriority  22  // choose next available number
   ```
3. **Syscall table entry** (`kernel/syscall.c`):
   ```c
   extern uint64 sys_setpriority(void);
   static uint64 (*syscalls[])(void) = {
       // ...
       [SYS_setpriority] sys_setpriority,
   };
   ```
4. **Kernel implementation** (`kernel/sysproc.c`):
   ```c
   uint64
   sys_setpriority(void)
   {
     int pr;
     argint(0, &pr);
     if(pr < 1 || pr > 10)
       return -1;
     struct proc *p = myproc();
     acquire(&p->lock);
     p->priority = pr;
     release(&p->lock);
     return 0;
   }
   ```
User applications can invoke: `setpriority(3);`

### Step 5 — Modifying the Scheduler for Strict Priority Scheduling
Replace the round-robin logic in `kernel/proc.c`:
- **Algorithm**: Scan all processes in `proc[]` to locate the `RUNNABLE` process with the lowest priority value (`bestpriority`), running only that process.
- **Design Choice**: Run exactly one process per outer loop iteration so newly awakened higher-priority processes preempt lower-priority ones immediately.

```c
void
scheduler(void)
{
  struct cpu *c = mycpu();
  c->proc = 0;
  for(;;){
    intr_on();
    intr_off();
    struct proc *bestproc = 0;
    int bestpriority = 11; // priorities are 1-10

    for(struct proc *p = proc; p < &proc[NPROC]; p++) {
      acquire(&p->lock);
      if(p->state == RUNNABLE && p->priority < bestpriority) {
        if (bestproc != 0) {
          release(&bestproc->lock);
        }
        bestpriority = p->priority;
        bestproc = p;
      } else {
        release(&p->lock);
      }
    }

    if (bestproc == 0) {
      // nothing to run
      asm volatile("wfi");
      continue;
    }

    bestproc->rounds++;
    c->proc = bestproc;
    bestproc->state = RUNNING;
    swtch(&c->context, &bestproc->context);
    c->proc = 0;
    release(&bestproc->lock);
  }
}
```

### Step 6 — Modify Procdump
Update `procdump()` in `kernel/proc.c` to output priority and rounds (accessible via `Ctrl + P` in QEMU):
```c
for(p = proc; p < &proc[NPROC]; p++) {
    if(p->state == UNUSED)
        continue;
    if(p->state >= 0 && p->state < NELEM(states) && states[p->state])
        state = states[p->state];
    else
        state = "???";
    printf("%d %s %s %d %d
", p->pid, state, p->name, p->priority, p->rounds);
}
```

### Step 7 — Testing the Priority Scheduler
1. Build test application `test_priority`.
2. Run test process with priority 5 in the background:
   ```bash
   $ test_priority 5 &
   ```
3. Press `Ctrl + P` to inspect output:
   ```text
   1 sleep  init 1 38
   2 sleep  sh 1 18
   6 run    test_priority 5 23
   ```
4. Start a higher-priority process:
   ```bash
   $ test_priority 4 &
   ```
5. Press `Ctrl + P` repeatedly. The priority 5 process round count stops advancing (e.g. fixed at 129), while priority 4 process increases turns:
   ```text
   1 sleep  init 1 39
   2 sleep  sh 1 23
   6 runble test_priority 5 129
   8 run    test_priority 4 14
   ...
   8 run    test_priority 4 27
   ```
This demonstrates strict priority scheduling preemption and ordering.\n
