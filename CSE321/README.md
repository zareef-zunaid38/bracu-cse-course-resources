# CSE321 — Operating Systems

Summer 2026 · theory: NTR · lab: MAFZ / SZD. Back to the [main README](../README.md).

## Start here (in this order)

1. **[Topic map](topics/cse321_topics.md)** — all 32 topics, which exam each belongs to (midterm or final), how they depend on each other, and a suggested study order. The [course index](topics/course-index.md) has the course outcomes and a list of every note.
2. **[Resources](resources/cse321_resources.md)** — for each topic: which textbook chapter, which practice sheet, and which slide deck to use.
3. **[Exam notes](cse321_exam_notes.md)** — who writes each assessment (the midterm and final are central; quizzes are NTR's), how each quiz and exam actually went, and what was asked. Read this before you decide how to prepare.
4. **The notes themselves** — [module notes](concepts) (`m1` to `m8`) and the faculty [slides](slides) (each `.pptx` has a text version beside it).
5. **Past papers** — [index](pyq/pyq_index.md), then the pattern analysis: [midterm](pyq/CSE321_midterm_probable_questions.md) and [final](pyq/CSE321_final_probable_questions.md).
6. **Practice** — [practice sheets](practice) (questions only), the [mock final](mock-exams/cse321_final_mock_exam.md), and the [revision guides](revision-guides).
